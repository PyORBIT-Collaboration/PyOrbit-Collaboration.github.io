Detailed Description
--------------------

This is a class based on a singleton pattern that keeps sets of one dimensional arrays. They will be used in MPI data exchanges.

This class is a methods to create random numbers

The Moments1D class calculates the arbitrary moments of the (u,up) distribution. It is used by other classes to calculate Twiss paraemeters etc.

The string utilits collection.
